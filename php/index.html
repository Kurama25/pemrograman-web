Apa itu Form Handling?

Form Handling adalah proses menangani data yang dikirimkan pengguna melalui formulir HTML (<form>) ke server. Dalam PHP, data tersebut ditangkap menggunakan superglobal variables seperti $_GET, $_POST, dan $_REQUEST.

Ketika pengguna mengisi form dan menekan tombol submit, browser akan mengirim data ke URL yang ditentukan pada atribut action. Metode pengiriman ditentukan oleh atribut method (GET atau POST).

Contoh Struktur Form Dasar

<form action="proses.php" method="post">
   <label for="nama">Nama:</label>
   <input type="text" name="nama" id="nama">
   <label for="email">Email:</label>
   <input type="email" name="email" id="email">
   <button type="submit">Kirim</button>
</form>

  • ✓ Menerapkan validasi dasar

Tangkap dengan superglobal

$_GET

Superglobal Array untuk Method GET

$_GET adalah PHP superglobal variable yang digunakan untuk mengumpulkan data yang dikirim melalui form dengan method="get" atau melalui parameter URL (query string).

💡 Kunci Penting: Data yang dikirim melalui GET akan terlihat di URL browser setelah tanda tanya ?, misalnya: index.php?nama=Budi&umur=20

Contoh Penggunaan $_GET

// form.html
<form action="welcome.php" method="get">
   Nama: <input type="text" name="nama">
   Email: <input type="email" name="email">
   <input type="submit">
</form>
// welcome.php
<?php
   echo "Selamat datang " . $_GET["nama"] . "<br>";
   echo "Email Anda: " . $_GET["email"];
?>

Validasi dengan isset()

<?php
   if (isset($_GET["nama"]) && !empty($_GET["nama"])) {
      $nama = htmlspecialchars($_GET["nama"]);
      echo "Halo, " . $nama;
   } else {
      echo "Nama belum diisi!";
   }
?>

Kelebihan $_GET

  • Bisa di-bookmark karena tampil di URL
  • Mudah di-share via link
  • Cocok untuk pencarian & filter
  • Di-cache oleh browser

Kekurangan $_GET

  • Tidak aman untuk data sensitif
  • Batas panjang URL ± 2048 karakter
  • Tidak bisa kirim file/binary
  • Data terlihat di history browser

Kapan Gunakan?

Gunakan GET untuk pencarian data, filter produk, paginasi, atau data yang tidak sensitif.

$_POST

Superglobal Array untuk Method POST

$_POST adalah PHP superglobal variable yang digunakan untuk mengumpulkan data yang dikirim melalui form dengan method="post". Data dikirim melalui HTTP request body, bukan URL.

🔒 Kunci Penting: Data POST tidak terlihat di URL, sehingga lebih aman untuk informasi sensitif seperti password, data login, atau data pribadi.

Contoh Penggunaan $_POST

// login.html
<form action="proses_login.php" method="post">
   Username: <input type="text" name="username">
   Password: <input type="password" name="password">
   <input type="submit" value="Login">
</form>
// proses_login.php
<?php
   if ($_SERVER["REQUEST_METHOD"] == "POST") {
      $user = htmlspecialchars($_POST["username"]);
      $pass = $_POST["password"];
      echo "Selamat datang, " . $user;
   }
?>

Best Practice: Sanitasi Input

<?php
   function bersihkan_input($data) {
      $data = trim($data);
      // hapus spasi
      $data = stripslashes($data);
      // hapus backslash
      $data = htmlspecialchars($data);
      // cegah XSS
      return $data;
   }
   $nama = bersihkan_input($_POST["nama"]);
   $email = bersihkan_input($_POST["email"]);
?>

Kelebihan $_POST

  • Lebih aman, tidak tampil di URL
  • Tidak ada batas ukuran data
  • Mendukung upload file
  • Data tidak tersimpan di history

Kekurangan $_POST

  • Tidak bisa di-bookmark
  • Tidak di-cache browser
  • Perlu submit ulang saat refresh
  • Tidak cocok untuk URL sharing

Kapan Gunakan?

Gunakan POST untuk login, registrasi, upload file, pembayaran, dan data sensitif lainnya.

Perbandingan $_GET vs $_POST

Tabel perbandingan komprehensif antara kedua metode pengiriman data.

Aspek $_GET $_POST
Visibilitas Data Terlihat di URL (query string) Tidak terlihat, dikirim via body
Keamanan Kurang Aman Lebih Aman
Batas Ukuran ± 2048 karakter (URL) Tidak terbatas (default)
Bookmark ✓ Bisa ✗ Tidak bisa
Cache Browser ✓ Ya ✗ Tidak
Upload File ✗ Tidak bisa ✓ Bisa (dengan enctype)
Tipe Data Hanya ASCII ASCII & binary
Riwayat Browser Tersimpan Tidak tersimpan
Penggunaan Ideal Pencarian, filter, paginasi Login, registrasi, upload

Contoh URL GET

https://toko.com/cari.php?produk=laptop&harga=5000000

Contoh URL POST

https://toko.com/login.php (data ada di body)
