A. Reset & Box Model

Perbandingan content-box vs border-box

Secara default, properti width hanya menghitung area konten. Aktifkan border-box agar padding dan border tidak membuat kotak membengkak!

Padding: 20px Border: 4px 
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
.kotak-ukur {
  width: 260px;
  padding: 20px;
  border: 4px solid #1e293b;
}
