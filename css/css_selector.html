Kuasai Group Selector & Targeting Elemen

Pelajari cara mengelompokkan beberapa elemen sekaligus (Grouping Selector) untuk menghindari duplikasi kode, serta cara menargetkan elemen HTML secara spesifik dan akurat tanpa merusak tata letak elemen lain!

Koma ( , ) = Grouping Spasi = Keturunan (Descendant) > = Anak Langsung (Direct Child)
1

Memahami Konsep Target & Grouping

Bagaimana cara menargetkan elemen dengan tepat dan efisien?

h1, h2, .title

1. Grouping Selector (Koma)

Digunakan untuk memberikan gaya yang sama pada beberapa elemen sekaligus. Dipisahkan dengan tanda koma (,). Ini sangat menghemat jumlah baris kode (DRY - Don't Repeat Yourself).

// Sebelum (Boros kode):
h1 { color: blue; }
h2 { color: blue; }

// Sesudah (Group Selector):
h1, h2 { color: blue; }
.card > p.highlight

2. Precision Targeting (Kombinasi)

Digunakan saat kita ingin menargetkan elemen secara spesifik berdasarkan lokasi/strukturnya agar elemen lain tidak tidak sengaja terkena dampaknya.

div p (Spasi)
Semua <p> di dalam <div> (Keturunan)
div > p (>)
Hanya <p> anak langsung dari <div>
h1.judul (Tanpa spasi)
Elemen <h1> yang memilik class 'judul'
